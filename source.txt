  Title Slide

  - Helmet Detection & Traffic‑Violation Detection System
  - Author: Nishant Rajora – B.Tech Computer Science & Data Science
  - Date: September 2026

  ---

  2️⃣  Project Overview

  - Deep‑Learning / Computer‑Vision pipeline that classifies helmet vs.
    no‑helmet on two‑wheeler riders.
  - Built on Ultralytics YOLO 11 (nano classification variant).
  - Serves as the first building block toward a full traffic‑violation
    monitoring platform (rider detection, number‑plate OCR, automated
    challan generation).

  ---

  3️⃣  Problem Statement

  - Helmet compliance is mandatory but manual CCTV monitoring is
    labor‑intensive and slow.
  - Need an automated, scalable solution that can flag violations in
    real time.

  ---

  4️⃣  Objectives (from README)

  1. Develop a DL‑based helmet detection system.
  2. Train a lightweight YOLO‑11 classification model.
  3. Achieve high‑accuracy helmet/no‑helmet classification.
  4. Validate on separate test data & external images.
  5. Provide a baseline for future rider‑level detection, plate OCR,
     etc.

  7️⃣  Model Architecture – YOLO 11 n (Classification)

  - Pre‑trained yolo11n-cls.pt (≈ 5 MB) downloaded automatically in
    training.ipynb.
  - Fine‑tuned on the helmet dataset (30 epochs, imgs = 640,
    batch = 16).
  - Model saved as saved_models/helmet_model.pt.

  ---

  8️⃣  Training Workflow (training.ipynb)

  - Dataset paths validated (train/val/test).
  - Classes discovered: helmet, no_helmet, overloading.
  - Callbacks: on_fit_epoch_end prints loss, Top‑1/Top‑5 accuracy,
    elapsed time.
  - Training config (see slide 9).
  - Results saved under
    runs/classify/Helmet_Runs/helmet_classification/.
  - Final model copied to saved_models/helmet_model.pt.

  Task           : Image Classification

  - Total training time shown in notebook (hours :min :sec).

  ▎ Note: Perfect validation scores likely reflect the limited dataset

  ---

  1️⃣ 1️⃣  Model Evaluation – Image Testing (testing.ipynb)

  - Loads saved_models/helmet_model.pt.
  - Downloads an external image via requests.
  - Runs model.predict(image).
  - Prints predicted class and confidence (e.g., no_helmet – 61.97 %).
  - Displays the image with a matplotlib title showing the prediction.

  ---

  1️⃣ 2️⃣  Video‑Based Detection (video_testing.ipynb)

  - Loads the same model, opens v1.mp4.
  - Processes video at target = 10 fps (skipping frames).
  - For each processed frame:
    - Performs YOLO prediction.
    - If class = no_helmet, draws confidence overlay and shows the
      frame.

  - Final summary prints total frames, processed frames, number of
    no‑helmet detections, and processing FPS.

  ---

  1️⃣ 3️⃣  Web Application (app.py)

  - Flask server (/ → static HTML page, /predict → JSON API).
  - Loads model once at startup (saved_models/helmet_model.pt).
  - HTML front‑end provides drag‑&‑drop upload, preview, and result
    display (prediction, confidence, class name, processing time).
  - Uses YOLO 11 for inference on CPU (or GPU if available).

  1️⃣ 7️⃣  Installation & Quick‑Start (from README)

  1. Clone repo.
  2. Create & activate a virtual environment (venv).
  3. Install dependencies:

  pip install ultralytics torch torchvision opencv-python \
      numpy pandas matplotlib jupyter
  4. Training – open training.ipynb and run all cells.
  5. Testing – open testing.ipynb (image) or video_testing.ipynb
     (video).
  6. Web UI – run python app.py and browse to http://127.0.0.1:5000.
